# v0.7.3 — draft changelog

## New machines

- Add ZX80 and ZX81 emulation with library
- Add CPC 6128 Plus and GX4000 (Amstrad's ASIC-based "Plus" range), including
  sprites, soft scroll, split-screen, DMA sound, `.CPR` cartridge loading
  (boots from a built-in cartridge out of the box), and `.SNA` snapshot support

## Other new features

- Xtal and MSX BASIC pane support
- Stepped speed control to the toolbar
- Grouped machine picker into submenus
